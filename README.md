# Kinetic C# Example Snippets

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Tired of kicking around for half a day trying to debug some custom code only to
find an example when you're about to head out? *Maybe this can help out.*

I try to organize snippets by what structures they operate on and what methods
they use. The same file may appear in multiple places because the logic it
contains uses multiple methods.

So far there are examples for

- BAQs
- UDXX methods
- Sending emails
- Reading changelogs

Some examples may come from other sources and I add attributions when possible.

## Background

Epicor is not necessarily vague about the syntax for their system, but it is
very hard to find. You can go looking for it by decompiling dlls or by reviewing
contract files and there are some small example snippets they have in their
actual documentation in EpicCare, but they are sparse, hard to find, and in most
cases don't tell the whole story.

There is [epiusers.help](https://www.epiusers.help/) which is very useful, but
solutions may not have exactly what you're looking for or there may be 5 threads
all talking about your problem but only 1 of them actually has your solution.
Plus, Jose Gomez and Hannah Willet only have so much time to give their wisdom.
